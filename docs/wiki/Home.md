# Release Relay

Release Relay helps small web agencies show a client which release was reviewed, what was checked, and what happens next. It separates a GitHub workflow result, a manual review of the site, and the decision to share a handoff.

O Release Relay ajuda agências a entregar um site com evidências. A entrega registra a versão revisada, a verificação manual e o próximo passo. Consulte o [início rápido em português](Inicio-rapido.md).
